## 🇧🇷 Português

### Sobre o Projeto

A **Calculadora de Dosagem Anestésica** é uma aplicação web desenvolvida para auxiliar profissionais da saúde no cálculo de doses de medicamentos anestésicos comumente utilizados. A ferramenta oferece cálculos precisos baseados em peso, idade e tipo de procedimento, sempre acompanhados de importantes disclaimers de segurança.

### Funcionalidades

- **Cálculo de Dosagens**: Propofol, Fentanil e Midazolam
- **Ajustes Automáticos**: Considerações para idade e peso
- **Design Responsivo**: Funciona em desktop, tablet e mobile
- **Histórico**: Últimos cálculos realizados
- **Disclaimers de Segurança**: Avisos médicos importantes
- **Interface Intuitiva**: Fácil de usar em ambiente clínico

### Tecnologias Utilizadas

- **React** 18+
- **React Hook Form** - Gerenciamento de formulários
- **Yup** - Validação de dados
- **Styled Components** - Estilização
- **React Icons** - Ícones

### Como Executar

#### Pré-requisitos
- Node.js (versão 14 ou superior)
- npm ou yarn

#### Instalação
```bash
# Clone o repositório
git clone https://github.com/seu-usuario/calculadora-dosagem-anestesica.git

# Entre na pasta do projeto
cd calculadora-dosagem-anestesica

# Instale as dependências
npm install

# Execute o projeto
npm start
